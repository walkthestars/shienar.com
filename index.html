Check every change your AI coding agent makes.

Polymorph sits underneath the coding agent you already use. It runs your tests on each change, has a separate reviewer grade the result, undoes anything that fails, and keeps a record of what happened.

Install

One command. No build tools needed.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/walkthestars/polymorph/releases/latest/download/polymorph-swe-installer.sh | sh
irm https://github.com/walkthestars/polymorph/releases/latest/download/polymorph-swe-installer.ps1 | iex

How it works

The agent decides what to build. Polymorph checks that it was built.

  1. You state the goal and how to check it. A sentence describing the change, the files involved, and the commands that must pass, such as your test suite.
  2. A model makes the edit. Each edit is verified against the exact lines it claims to change, so a stale edit cannot quietly corrupt a file.
  3. Your checks run. If a command you declared fails, the change cannot pass, whatever the reviewer says.
  4. A separate reviewer grades it. It sees the goal, the result and the check output, not the first model's reasoning, and returns pass or fail with findings.
  5. Pass, or put everything back. A change that does not pass is undone, byte for byte, and the attempt is archived.

Your tests have the last word

Failing checks veto a passing review. The model cannot talk its way past them.

Failed changes are undone

Files are restored to their original bytes when a change fails or is interrupted.

A record of every round

Each attempt, verdict and finding can be written to a file a person or another tool can read.

Your models, your keys

Use the provider you already have, or a self-hosted endpoint. Nothing is sent to us.

Also included, marked experimental: a proof gate that checks stated properties of small units with an SMT solver and writes a certificate that can be re-checked. Details are in the documentation.
